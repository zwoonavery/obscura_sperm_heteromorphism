# Perform Analysis and Generate Figures
This folder includes all analyses and graphical representation outlined in our paper. The analyses are performed on the outputs generated in (`../workflow/`). Thus, those pipelines must be run before performing the scripts included here. All packages are loaded in the beginning of the notebooks in order to list the requirements for code reproduction. Additionally, (`rkernel.yaml`) creates the environment that these scripts were initially ran in. 

If all inputs are provided, each notebook is formatted to be ran in their entirety. To further support reproducing the code included, each notebook is sectioned for ease of use. (`R_analysis_zwa.ipynb`) has overarching headers for analysis types performed, loads the required data input for each section, as well as breaks each overarching section into subsections for each independent analysis. (`R_figures_zwa.ipynb`) includes the code needed to generate each figure in our paper, with each code chunk labeled correspondingly, including the supplemental figures.
